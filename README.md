# Workshops

- [`docker-workshop/`](docker-workshop/) — "Docker for the Team" (~90 min):
  fundamentals, image building, docker run in practice, debugging & ops.
  Run-sheet: `docker-workshop/DEMO-SCRIPT.md`.
- [`compose-workshop/`](compose-workshop/) — "Docker Compose for the Team"
  (~90 min, follow-up): the stack as a file, networks, volumes, healthchecks and
  depends_on gates, build targets, .env, lifecycle gotchas, the override
  pattern, profiles, Compose in CI, debugging a stack.
  Run-sheet: `compose-workshop/DEMO-SCRIPT.md`.
